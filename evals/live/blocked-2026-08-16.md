# Live stack blocked — 2026-08-16

The live Cognee stack could **not** be stood up in this session. Both prerequisites
(LLM egress and an LLM API key) are missing. Nothing was simulated or mocked; no
live smoke was attempted.

## What was probed

Probed at 2026-08-16T22:28Z from the remote execution container (outbound HTTPS
goes through the session's agent proxy).

### 1. LLM egress — BLOCKED

```
curl -sS --max-time 10 -o /dev/null -w "%{http_code}" https://openrouter.ai/api/v1/models
→ curl: (56) CONNECT tunnel failed, response 403   (reported status: 000)

curl -sS --max-time 10 -o /dev/null -w "%{http_code}" https://api.openai.com/v1/models
→ curl: (56) CONNECT tunnel failed, response 403   (reported status: 000)
```

The proxy status endpoint (`$HTTPS_PROXY/__agentproxy/status`) confirms these are
policy denials at the gateway, not transient network errors — `recentRelayFailures`:

```json
[
  {"ts": "2026-08-16T22:28:53.548Z", "kind": "connect_rejected",
   "detail": "gateway answered 403 to CONNECT (policy denial or upstream failure)",
   "host": "openrouter.ai:443"},
  {"ts": "2026-08-16T22:28:53.855Z", "kind": "connect_rejected",
   "detail": "gateway answered 403 to CONNECT (policy denial or upstream failure)",
   "host": "api.openai.com:443"}
]
```

No HTTP status from the upstream APIs was ever received (even a 401 would have
meant the path is open). The CONNECT itself is rejected, so the network path to
both providers is closed.

### 2. LLM API key — MISSING

```
env | grep -E "OPENROUTER_API_KEY|OPENAI_API_KEY|LLM_API_KEY"
→ (no matches)
```

None of `OPENROUTER_API_KEY`, `OPENAI_API_KEY`, or `LLM_API_KEY` is set in the
container environment.

## What is needed to unblock

1. Environment network policy must allow egress to at least one LLM provider
   host (`openrouter.ai:443` and/or `api.openai.com:443`) — currently the proxy
   answers 403 to the CONNECT.
2. An API key exported into the environment (`OPENROUTER_API_KEY` or
   `OPENAI_API_KEY` / `LLM_API_KEY`).

Once both are in place in a fresh session, run from the repo root:

```
uv sync --extra dev --extra temporal --extra opt --frozen
uv run python scripts/live_stack.py
```
